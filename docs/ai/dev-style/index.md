# 開発スタイル

AI を活用したソフトウェア開発のアプローチ。

- [AI 駆動開発ライフサイクル（AI-DLC）](/ai/dev-style/ai-dlc) — AI を各開発フェーズに統合したプロセス設計
- [Vibe Coding](/ai/dev-style/vibe-coding) — 自然言語でコードを書くAI駆動の開発スタイル
- [Harness Engineering](/ai/dev-style/harness-engineering) — AIコーディングツールの動作環境を設計・構成するパターン
- [Loop Engineering](/ai/dev-style/loop-engineering) — エージェントに指示を出すループ自体を設計するアプローチ
- [Graph Engineering](/ai/dev-style/graph-engineering) — 複数の実行単位を有向グラフとして構造化する方法論
